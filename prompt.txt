Your goal is to train a model that achieves a >94% test accuracy on EuroSAT in as few parameters as possible. I'll repeat: for a model submission to be valid, it needs to have >94% test accuracy on EuroSAT, and is scored based on the number of parameters it has. You can only train on the EuroSAT train split and validate on the val split. If you find some silly approach wins (e.g. computing per patch image statistics then fitting a logistic regression model on top of those), change the threshold to 95% or 96% to make it more difficult, then keep trying. The repo contains a very simple training script that you can start branching off of. Make a src/ folder that has reusable components. Then make each "submission" its own folder that contains its own trained checkpoint(s) and a markdown description of what you are doing and why -- these submissions can import from src/ if they want. Try crazy things, e.g., distilling really good pre-trained models down into few conv layers, ZCA whitening to get good inits, feel free to seed hack, literally do whatever you want -- but should only use a few parameters. Run experiments in parallel over the 8 GPUs we have here. Review you results periodically to come up with new ideas and save these thoughts in markdown files that are timestamped.
